# Sarabesh

Public demo: https://sandy.tayts.com/sarabesh/

This directory is the maintained browser release, published by the portfolio main branch workflow. Update the runtime and selected assets here, commit, and push main to update the same URL. Keep asset references relative so the demo works under /sarabesh/.

Ten scenes, 64 full-resolution lighting states. Panorama zoom is locked. Source and asset production tools: https://github.com/liza-bam/explorable-world
